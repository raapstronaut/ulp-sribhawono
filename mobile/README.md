# Mobile ULP Sribhawono (Flutter Android)

Aplikasi untuk **POSKO, HARSUS, INSPEKSI, ROW** saja. **ADMIN hanya Web Laravel**.

Proyek Flutter saat ini masih fondasi/placeholder. Login tim, daftar pekerjaan, GPS, kamera, navigasi Google Maps, dan auto-sync SQLite **belum diimplementasikan**.

```sh
flutter pub get
flutter test
flutter run
```

Rujuk `../docs/DESIGN_BRIEF.md` dan `../docs/OFFLINE_SYNC_SPEC.md`. Form nantinya menggunakan dropdown berbasis database, bukti foto sesuai work type, submission lokal tahan restart dan pengiriman otomatis *best effort*.
